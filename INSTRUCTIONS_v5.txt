WHY THE # IN THE ADDRESS?
GitHub Pages is a static host with no server-side routing. With normal
addresses, refreshing /gallery would return a 404 error. Hash routing
(/#/gallery) always loads correctly, including refresh and back/forward
buttons. This is intentional and was tested.

16. TROUBLESHOOTING
--------------------------------------------------------------------------------
PROBLEM: GitHub Actions run is red / site did not update.
 - Did you set Settings > Pages > Source to "GitHub Actions"? (Section 9)
 - Is .github/workflows/deploy.yml actually in the repo? The web uploader
   often misses hidden folders — re-add it using GitHub Desktop or git.
 - Open the failed run > build job. If "Install dependencies" failed, the
   usual cause is a missing or damaged package-lock.json — re-upload it.

PROBLEM: The site loads but looks unstyled / blank.
 - Hard-refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac).
 - Confirm you did NOT change  base: '/'  in vite.config.ts. This is a
   user site served from the root; it must stay '/'.

PROBLEM: npm run build fails on your computer with a TypeScript error
mentioning node:url — run  npm install  again so @types/node is installed,
then rebuild.

PROBLEM: npm commands say "command not found" — Node.js is not installed
or the terminal was open during installation. See section 1, then open
a NEW terminal.

PROBLEM: Gallery photo shows as a broken image.
 - The file name in src/data/gallery.ts must match the file in
   public/assets/gallery/ EXACTLY, including capitals, and start with
   /assets/gallery/
 - Remember: only files inside public/ are copied to the live site.

PROBLEM: Contact form still says "not connected yet" after Formspree setup.
 - You edited a copy of site.ts that was not pushed, or the push did not
   trigger a successful Actions run. Check the Actions tab for green.

PROBLEM: Form says it sent, but nothing arrives.
 - Check spam. Confirm the Formspree form's destination email, and
   complete Formspree's verification email. Send a fresh test afterwards.
